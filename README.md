# پورتفولیو متین

من متینم و فرانت‌اند کار می‌کنم.
این ریپو، سایت شخصی منه برای جمع کردن تمرین‌ها و پروژه‌هام.

نسخه آنلاین: https://matin-dvl.github.io/Portfolio-/

## درباره من

با HTML و CSS شروع کردم و با تمرین و پروژه جلو رفتم.
بعد تیلویند رو اضافه کردم و الان دارم جاوااسکریپت یاد می‌گیرم.
روش یادگیریم پروژه‌محوره، یعنی با ساختن یاد می‌گیرم.

## مهارت‌ها

- HTML ،CSS
- Tailwind CSS
- JavaScript در حد مقدماتی
- ریسپانسیو با Flexbox و Media Query
- Git و GitHub

## پروژه‌ها

### ۱. شمارنده
شمارنده ساده با دکمه‌های کم، زیاد و ریست.
بین ۰ تا ۱۰ محدوده و عددش با localStorage بعد از رفرش می‌مونه.

تکنولوژی: HTML ،CSS ،JavaScript

### ۲. تودو لیست
اضافه کردن کار، تیک زدن، حذف و شمارنده کارهای مونده و انجام‌شده.

تکنولوژی: HTML ،Tailwind ،JavaScript

تمرینم روی این پروژه: آرایه، آبجکت، forEach ،render از روی state

### ۳. همین پورتفولیو
همین سایتی که الان می‌بینی. چیدمان ساده و ریسپانسیو برای معرفی خودم و پروژه‌هام.

تکنولوژی: HTML ،Tailwind

## اجرای محلی

```bash
git clone https://github.com/matin-dvl/Portfolio-.git
cd Portfolio-
```

بعد فایل `index.html` رو توی مرورگر باز کن.
نیازی به بیلد نداره.

## الان دارم روی چی کار می‌کنم

- تکمیل تودو لیست: حذف، localStorage و حالت لیست خالی
- ادامه جاوااسکریپت: filter ،find و کار با API
- تمیزتر کردن ریسپانسیو و تیلویند
